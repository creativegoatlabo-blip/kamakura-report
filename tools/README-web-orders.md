# WEBオーダー欄の更新

通常月次の生成後に `python3 tools/build_web_orders.py` を実行する。全店の最新ページと、集計データがある月の全店アーカイブに追加する。再実行で重複しない。既存の予約・費用・CPA・売上・ナビゲーションは再生成しない。

元データはログイン済みChromeの本店管理画面「WEBオーダー」一覧。受付日、種類、ステータスを読み取り、氏名にテスト・てすと・testを含む登録を除く。個人情報・注文明細・認証情報は保存・公開しない。`assets/web-orders-summary.json` は月・種類・状態別の匿名集計だけを保存する。

- 集計期間は通常月次の締め日と揃える。未確認月を0件として追加しない。
- 有効受付は製作中＋納品済み。見積中とキャンセルは別計上する。
- 「別途見積」の印を見積中と数えない。受付月と納品月を混同しない。
- 売上、見積からの成約率、前年実績は別途検証できるまで未取得。店舗予約合計・CPAに加算しない。
- 現在の仕様では全店ページのみに表示する。各店舗へ割り当てない。
