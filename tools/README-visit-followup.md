# 見学からの30日・90日予約率

`visit_followup.py` は個人情報を含む入力を保存せず、匿名の月・店舗別集計を返す。
公開HTMLには集計値のみを埋め込む。入力行や照合キーを公開・コミットしない。

- 見学予定日を0日、ブライダル予約の受付日を転換日とする。
- 集計締切までに30日または90日経過した組だけを分母・分子へ含める。期間はそれぞれ0〜30日、0〜90日。
- 未経過の予約済み組も除外。母数0は率null。追跡未完了が残る月は暫定。
- 既存と同じ正規化・完全一致規則で代表者・同伴者、電話、メールを照合し、全店舗で同一組をまとめる。照合対象期間内の最初の見学店舗・月へ帰属する。
- 対象は結婚指輪・3本制作・婚約指輪・ダイヤモンドプロポーズ。取消、テスト、見学前の受付を除外する。
- 締切後の受付はグループ照合・分子・分母のいずれにも使用しない。制作予定日が締切後であっても受付が対象なら計上する。
- `calculate_followup(rows, cutoff, start)` の既定開始日は2026-07-01。今回の11月版は11/5、10月版は10/31締切。過去月を再生成する際もその月の締切を明示する。
- 全店と店舗別の件数を照合し、`validate_followup` で率・追跡状態を検証する。
